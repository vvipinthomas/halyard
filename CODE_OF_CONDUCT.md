# Code of conduct

We want Halyard to be a welcoming project for everyone.

**Expected:** be respectful and constructive, assume good intent, credit others' work, and accept that maintainers make final calls on scope.

**Not acceptable:** harassment, discrimination, personal attacks, sharing others' private information, or sustained disruption.

**Reporting:** contact the maintainers privately through the repository's private reporting channel (GitHub: Security → "Report a vulnerability"; GitLab: a confidential issue). Reports are handled confidentially. Maintainers may warn, temporarily restrict, or remove participants who breach this code.

This code applies in all project spaces and when representing the project in public.
