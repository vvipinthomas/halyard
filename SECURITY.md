# Security policy

## Reporting a vulnerability
Please report privately through GitHub Security Advisories ("Report a vulnerability" on the repository) rather than a public issue. Include steps to reproduce and impact. We aim to acknowledge within 3 business days and to agree a disclosure timeline with you.

## Supported versions
The latest minor release receives security fixes.

## Scope notes
- The product's security design, known residual risks and SOC 2 mapping are in `docs/security/`.
- MCP servers listed in the catalogue are third-party software; report issues in them to their maintainers.
